# Hs-awwwards website clone
______________________________________

I developed a high-fidelity clone of the HS Awwwards website, highlighting premium hotels, villas, and residences with a luxurious and immersive design.
Built using HTML, CSS, and JavaScript, the project features smooth scroll-based animations, refined transitions, and a fully responsive layout that
adapts seamlessly across devices. Special attention was given to creating an elegant user interface and delivering an exceptional user experience through 
intuitive navigation and dynamic visual effects. This project reflects my proficiency in front-end development, with a strong emphasis on aesthetic
design.
